# 交付清单与验收记录

日期：2026-08-03

## 交付组件

- `server/pbd_brain_http_server.py`：运行在 PBD Ubuntu 主机上的 HTTP 网关。
- `server/start_pbd_brain_server.sh`：服务启动、状态查询和停止脚本。
- `client/pbd_ag_client/`：无第三方运行依赖的 Python 3.10 客户端源码。
- `dist/pbd_ag_client-0.1.0-py3-none-any.whl`：可直接安装于 macOS arm64 的轻量 wheel。
- `dist/PBD_AG_大脑端轻量客户端_v0.1.0.zip`：可直接发送给大脑同事的压缩包。
- `client/examples/`：一次性查询与事件轮询示例。
- `client/windows/acceptance.ps1`：Windows 一键安装和只读验收脚本。
- `tests/smoke_test.py`：不下发导航命令的只读验收脚本。
- `README_操作指南.md`：双方完整启动、联调和排障步骤。
- `Windows端临时大脑测试指南.md`：Windows 临时替代 macOS 的完整操作流程。
- `API接口说明.md`：字段、坐标、接口、错误码和安全约定。

## 已完成验收

- 服务端及客户端全部通过 Python 语法检查，启动脚本通过 Bash 语法检查。
- 服务端在独立进程中成功监听并生成 PBD 世界模型导出。
- 全新 Python 虚拟环境从 wheel 安装成功，证明客户端不依赖 DREAM、ROS2、CUDA 或模型环境。
- `/health`、世界快照、类别过滤、稳定物体 ID、地图 YAML/PGM、RGB、任务上下文和增量事件接口均通过。
- 当前回放会话导出了 8 个语义物体节点；地图和 RGB 文件可正确下载。
- 导航未配置时的 fail-closed 行为通过：返回 `PENDING_NAV_ADAPTER` 并明确声明未发送运动命令。
